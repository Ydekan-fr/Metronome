# Ydeclik (Android)

Métronome Android (Kotlin / Jetpack Compose) avec exercices, routines et setlists.

## Fonctions
- **Métronome** : tempo, subdivisions, accents/silences par temps, signatures rythmiques, mode auto (mesures muettes, aléatoire ou régulier, ou ajout de BPM), 9 presets, tap tempo, son et balance. Volume = touches du téléphone. Appui long sur ± : pas de 5.
- **Exercices** : fichiers JPG/PNG/PDF (galerie, album, fichiers), tri, BPM de départ modifiable, dernier BPM, cible. PDF multi-pages : BPM distinct par page. Double toucher = plein écran. Pincer = zoom.
- **Routines** : playlists d'exercices avec minuteur par exercice (alerte vibration + bip, passage automatique optionnel).
- **Setlists** : presets nommés (BPM, métrique, accents), réordonnables par glissé, mode Édition et mode Live (grand bouton, précédent/suivant, balayage optionnel, preset suivant affiché).
- **Utilisation** : temps passé dans l'application par jour.
- Écran toujours allumé ; le métronome s'arrête lors d'un appel (voix ou vidéo).

## Compilation
Poussez le dossier sur GitHub : le workflow `.github/workflows/build.yml` produit l'APK (onglet Actions > Artifacts).
