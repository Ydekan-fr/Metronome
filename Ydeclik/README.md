# Ydeclik (Android)

Ouvrir le dossier `Ydeclik` dans Android Studio (Koala ou plus récent), laisser la synchronisation Gradle
se terminer (Android Studio génère le wrapper Gradle), puis Run sur un téléphone ou un émulateur
(Android 8.0 / API 26 minimum).

Pour un APK : Build > Build Bundle(s) / APK(s) > Build APK(s).
